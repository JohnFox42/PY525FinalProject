# PY525FinalProject

## Introduction
This is my final project for my computational physics class at NC State University. My goal is to create an abelian sandpile model to model how self organized criticality creates ski trails on mountains after random snowfall. That is to say, even though the snowfall might be random, through avalanches and instability organized trails are formed. When this happens it is called self organized criticality.
